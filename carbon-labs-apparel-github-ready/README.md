# Carbon Labs Apparel

Static Carbon Labs apparel landing page for Cloudflare Pages.

## Cloudflare Pages settings
- Framework preset: None
- Build command: `exit 0`
- Build output directory: `/`
- Production branch: `main`

## EZFormz links
Replace the `PASTE_EZFORMZ_LINK_...` placeholders in `index.html` with the final individual EZFormz URLs.
